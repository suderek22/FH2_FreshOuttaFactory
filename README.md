# FreshOuttaFactory

An FH2 Mod Platform mod for Forza Horizon 2 (Azimuth) that keeps
every car showroom-fresh:

* **No crash damage (all cars)** - cars never show visual crash damage: no dents, scratches,
  deformation or parts falling off. Unlike the game's own damage option, which only covers the
  player's car, this works globally - your car **and every Drivatar**. The game's mechanical
  damage simulation is untouched (use the game's Damage difficulty setting for that).
* **Always clean (no dirt)** - dirt and mud never build up on any car; a car that is already
  dirty is wiped clean the moment it moves.

Both switches are on the in-game Mods page (**Pause > Settings > MODS**) and work while driving.
Settings persist in `FreshOuttaFactory.ini` next to the DLL.


## Install

Copy `FreshOuttaFactory.dll` into the `fh2-mods` folder next to `azimuth.exe`.
Requires the FH2 Mod Platform (2.2.0 or newer; built against 2.8.0).
